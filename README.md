# Catálogo web

Catálogo de productos construido con Jekyll.

## Tecnologías

- Jekyll 4.4
- Liquid
- HTML
- CSS
- JavaScript
- Git

## Desarrollo local

Instalar las dependencias:

```bash
bundle install
```
Iniciar el servidor de desarrollo:

```bash
bundle exec jekyll serve
```

El sitio estará disponible en:

http://localhost:4000/catalogo/⁠

## Estructura

La estructura del proyecto se encuentra organizada para separar:

- configuración
- contenido
- componentes reutilizables
- estilos
- JavaScript
- datos de productos
